# FitClub App v2.0 (New Version)

## 🚀 راهنمای نصب و اجرا در سیستم جدید

### ۱. نصب پکیج‌ها:
در ترمینال، وارد پوشه پروژه شوید و دستور زیر را اجرا کنید:
```bash
npm install
```

### ۲. اجرای برنامه:
پس از اتمام نصب، برای اجرای پروژه در مرورگر دستور زیر را بزنید:
```bash
npm start
```

پروژه به صورت خودکار در مرورگر در آدرس `http://localhost:3000` (یا پورت پیشنهادی) باز خواهد شد.
